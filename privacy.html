隐私政策

冲一杯（以下简称"本应用"）由 Mihra Sanem Erdogan（以下简称"我们"）开发和运营，是一款手冲咖啡记录与引导冲煮工具。本政策说明本应用会处理哪些信息、为什么处理、与谁共享，以及你可以如何管理这些信息。请在使用前仔细阅读。

1. 只保存在手机上的数据

你在本应用中记录的内容，包括冲煮配方、豆子信息、冲煮记录、风味评分、照片、咖啡馆音景偏好以及各项设置，都保存在你手机上本应用的私有存储中。

这些数据不会上传到我们的服务器，我们也无法查看。删除本应用时，系统会一并删除这些数据。

2. 我们收集的信息

意见反馈

当你在"我的 → 意见反馈"中提交内容时，我们会收到：你填写的反馈内容和一个随机生成的设备标识。设备标识用于区分设备、防止重复提交，不包含你的姓名或手机号。这些信息只用于处理你的反馈和改进产品。

广告相关

本应用使用第三方广告 SDK 为你提供部分音景的免费解锁。广告仅在你主动点击「观看广告解锁」时加载和展示，不会在其他页面自动弹出。在首次展示广告前，系统会弹出「允许跟踪」弹窗，你可以选择允许或拒绝，不影响使用。

广告 SDK 可能会收集设备标识符（IDFA，仅在你允许跟踪后获取）和广告交互数据，用于提供与你相关的广告。

3. 第三方组件

本应用集成了第三方广告服务 SDK，用于在你主动选择「观看广告解锁」时展示激励视频广告。广告 SDK 可能会收集设备标识符和广告交互数据。核心功能（配方管理、引导冲煮、豆仓、手记等）可以完全离线使用，不受广告服务影响。

数据类型用途关联身份用于跟踪
设备 ID（IDFA）第三方广告、分析否是（需你授权）
广告数据第三方广告否是（需你授权）
崩溃数据App 功能改进否否
产品交互分析否否
反馈内容App 功能否否

4. 系统权限

  • 相机：拍摄咖啡豆包装或冲煮成品照片，保存到豆仓与手记中。
  • 照片（读取）：从相册选择咖啡豆或冲煮照片。
  • 照片（添加）：把冲煮分享卡片保存到相册。
  • 面容 ID / 密码：开启隐私锁后用于解锁。验证由系统完成，我们无法获取你的生物特征。
  • 通知：晨间提醒、豆子赏味期与库存提醒，以及引导冲煮的换步提示，均为本地通知。
  • 后台音频：让咖啡馆音景和冲煮提示音在锁屏后继续播放。
  • 本地网络：仅用于"投放到电视或音箱"时发现同一 Wi-Fi 下的 DLNA 设备。

所有权限都可以在 iPhone 的"设置 → 冲一杯"中随时关闭，关闭某项权限不影响其他功能。

5. 共享与披露

我们不会出售你的个人信息，也不会把冲煮记录提供给第三方。第三方广告 SDK 在你选择观看广告时可能会收集设备标识符和广告交互数据（详见第 3 节）。除此之外，我们不会与其他公司共享你的个人信息，除非获得你的明确同意，或法律法规、诉讼、政府主管部门依法要求。

6. 存储期限与安全

手机上的数据保存到你删除为止。意见反馈信息在处理所需的期限内保存，之后删除或匿名化。

我们使用请求签名等措施防止数据被篡改或冒用，但任何系统都无法做到绝对安全。如发生个人信息安全事件，我们会按法律要求及时告知你。

7. 你的权利

  • 查看与导出：在"我的 → 数据与备份"中导出完整备份（JSON）或冲煮记录（CSV）。
  • 删除：在"我的 → 数据与备份 → 清空全部数据"中删除，或直接删除本应用。
  • 撤回授权：在 iPhone 的"设置 → 冲一杯"中关闭相应权限。
  • 其他请求：如需删除你提交过的反馈，或有其他隐私相关请求，请发邮件给我们，我们会在 15 个工作日内答复。

8. 未成年人

本应用面向成年咖啡爱好者。未满 14 周岁的用户请在监护人陪同下阅读本政策，并在监护人同意后使用。如果我们发现在未获监护人同意的情况下收集了儿童的个人信息，会尽快删除。

9. 政策更新

本政策更新时，我们会在本页面发布新版本并修改更新日期；重大变更会在应用内提示你。
