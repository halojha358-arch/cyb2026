快速上手

  1. 首次打开完成引导：设置昵称和默认参数。
  2. 在"冲煮"页选择一个配方，点"开始冲煮"进入引导模式。
  3. 跟着倒计时和水量提示一步一步来，每步会有提示音和震动。
  4. 冲完后可以记录风味评分、选择用的豆子，保存到手记。
  5. 在"豆仓"中管理你的咖啡豆，记录烘焙日期和剩余量。
  6. 在"手记"中翻阅每一杯的参数和口感。
  7. "咖啡馆音景"可以在冲煮时播放背景音，锁屏后也会继续。

常见问题

冲煮时提示音没有响？

请确认手机没有开静音模式，并在"我的 → 外观与触感"中确认"步骤提示音"已开启。如果使用了蓝牙耳机，提示音会从耳机播放。

音景锁屏后停止了？

音景支持锁屏后继续播放。如果被来电或其他应用的声音打断，回到"咖啡馆音景"页重新点播放即可。也请确认没有设置定时关闭。

怎么自建配方？

在"冲煮"页右上角点 ＋，选择器具、填写参数和步骤即可。也可以从已有配方点"编辑"复制一份再修改。

我的数据保存在哪里？会上传吗？

配方、豆子、冲煮记录、照片和设置都只保存在你的手机上。只有你主动提交"意见反馈"时，反馈内容才会发送到我们的服务器。详见隐私政策。

换手机时怎么迁移数据？

在旧手机"我的 → 数据与备份 → 导出完整备份"，把 JSON 文件存到"文件"或发给自己；在新手机"我的 → 数据与备份 → 恢复"中选择这个文件。

怎么删除全部数据？

在"我的 → 数据与备份 → 清空全部数据"中确认即可删除，删除后无法恢复。也可以直接删除本应用。

豆子的「赏味期」是怎么算的？

根据烘焙日期和烘焙度，参考精品咖啡行业通用的养豆和赏味期窗口估算。浅焙豆的赏味期比深焙更长。结果仅供参考。

怎么把音景投放到电视或音箱？

在"咖啡馆音景"页底部点"投放到电视或音箱"，应用会搜索同一 Wi-Fi 下支持 DLNA 的设备。搜到后选择设备即可。如果搜不到，请确认已允许冲一杯访问"本地网络"。

开启隐私锁后面容 ID 识别失败？

可以改用设备密码解锁。如需关闭隐私锁，在"我的"页验证身份后关闭。
